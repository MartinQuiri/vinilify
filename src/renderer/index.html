      Opcional · unos 5 minutos

      Conecta tu cuenta de Spotify

      Con tu propia API de Spotify, Vinilify suma el buscador, la cola «A continuación» y «Me gusta». Spotify solo permite estas funciones a apps registradas por cada usuario. Crearla es gratis y se hace una sola vez. Todo lo demás funciona sin esto.

      1. Abre el panel de desarrolladores de Spotify

        Inicia sesión con tu cuenta de Spotify y pulsa Create app.

      2. Completa el formulario así

        App name
        Vinilify
        App description
        Vinilo de Spotify en mi escritorio
        Website
        Déjalo vacío
        Redirect URIs
        http://127.0.0.1:8888/callback
        Pégalo y pulsa Add. Tiene que ser exactamente este.
        Which API/SDKs…?
        Marca solo Web API

        Acepta los términos y pulsa Save.

      3. Copia el Client ID y pégalo aquí

        Aparece arriba en la página de tu app recién creada.

      Spotify pide que la cuenta que crea la app tenga Premium. Tus datos quedan solo en este PC.
